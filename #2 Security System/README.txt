🛡️ Security System  ระบบรักษาความปลอดภัย

🧹 Input Validation (อินพุต วาลิเดชัน)
ตรวจสอบข้อมูลที่ผู้ใช้ส่งเข้ามาว่าถูกต้องและอยู่ในรูปแบบที่ระบบยอมรับ

💉 SQL Injection Prevention (เอสคิวแอล อินเจกชัน พรีเวนชัน)
ป้องกันการแทรกคำสั่ง SQL ผ่าน Input ของผู้ใช้

🕷️ XSS Prevention (เอ็กซ์เอสเอส พรีเวนชัน)
ป้องกัน Script อันตรายที่ถูกแทรกเข้าไปในหน้าเว็บ

🔄 CSRF Protection (ซีเอสอาร์เอฟ โพรเทกชัน)
ป้องกันการหลอก Browser ให้ส่ง Request ที่ผู้ใช้ไม่ได้ตั้งใจ

🌐 CORS (คอร์ส)
กำหนดว่า Origin (ออริจิน) ใดสามารถเรียก API ผ่าน Browser ได้

🚦 Rate Limiting (เรต ลิมิตทิง)
จำกัดจำนวน Request เพื่อป้องกันการยิง API จำนวนมากเกินไป

🔨 Brute-force Protection (บรูตฟอร์ซ โพรเทกชัน)
ป้องกันการลอง Password หรือ OTP ซ้ำ ๆ จำนวนมาก

🔐 Encryption (เอนคริปชัน)
เข้ารหัสข้อมูลเพื่อไม่ให้ผู้ที่ไม่มี Key อ่านข้อมูลได้

#️⃣ Hashing (แฮชชิง)
แปลงข้อมูลเป็น Hash ที่ไม่ควรย้อนกลับเป็นข้อมูลเดิมโดยตรง เช่น Password

🔑 Secret Management (ซีเคร็ต แมเนจเมนต์)
จัดการข้อมูลลับ เช่น Password, API Key, JWT Secret อย่างปลอดภัย

🧱 Security Headers (ซีเคียวริตี เฮดเดอร์ส)
ใช้ HTTP Headers เพื่อเพิ่มการป้องกันด้านความปลอดภัยของ Browser

🔒 HTTPS / TLS (เอชทีทีพีเอส / ทีแอลเอส)
เข้ารหัสการสื่อสารระหว่าง Client กับ Server

📁 File Upload Security (ไฟล์ อัปโหลด ซีเคียวริตี)
ตรวจสอบไฟล์ที่ Upload เช่น ขนาด ชนิด เนื้อหา และสิทธิ์การเข้าถึง

➕ ส่วนที่ควรเพิ่ม
🍪 Cookie Security (คุกกี ซีเคียวริตี)
ป้องกัน Cookie สำคัญด้วย HttpOnly, Secure, SameSite

🪪 Session Security (เซสชัน ซีเคียวริตี)
ควบคุมอายุ การหมดอายุ การยกเลิก และการเปลี่ยน Session

🎫 Token Security (โทเคน ซีเคียวริตี)
จัดการ Access Token / Refresh Token ให้ปลอดภัยและมีอายุเหมาะสม

👮 Least Privilege (ลีสต์ พริวิเลจ)
ให้ User / Service / Database มีสิทธิ์เท่าที่จำเป็นเท่านั้น

🕵️ Audit Log (ออดิท ล็อก)
บันทึกว่าใครทำอะไรกับข้อมูล เมื่อไหร่ เพื่อใช้ตรวจสอบย้อนหลัง

🚨 Security Monitoring (ซีเคียวริตี มอนิเทอริง)
ตรวจจับพฤติกรรมผิดปกติ เช่น Login ผิดจำนวนมาก หรือ API ถูกยิงผิดปกติ

🧯 Security Error Handling (ซีเคียวริตี เออเรอร์ แฮนดลิง)
ไม่เปิดเผยข้อมูลภายใน เช่น SQL Error, Password, Secret หรือ Stack Trace ให้ผู้ใช้

🛑 Account Lockout (แอ็กเคานต์ ล็อกเอาต์)
จำกัดหรือระงับบัญชีชั่วคราวเมื่อพบการพยายาม Login ผิดปกติ
